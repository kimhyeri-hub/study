# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a personal study notes repository for learning VibeCoding and related CS topics. Content is written in Korean and organized by topic as Markdown files.

## Repository Structure

Notes are organized into topic folders, each containing a `README.md`:

- `programing/` — VibeCoding concepts: definitions, the iterative prompt cycle, and AI coding tools (Cursor, Replit, Windsurf, Claude Code, Gemini CLI)
- `Data Structures/` — Data structure theory: classifications (linear/non-linear/file), FIFO/LIFO/Deque, and binary data representation
- `Spring/` — Spring framework notes (placeholder)
- `Cloud/` — Cloud computing notes (placeholder)

Weekly study files (e.g. `programing/week4`) are also added under topic folders.

## Working in This Repo

- All content is Markdown. No build, lint, or test commands apply.
- Notes are written in Korean; preserve the language when editing existing notes.
- Follow the existing heading hierarchy (`##`, `###`) and table formatting style already used in `programing/readme.md` and `Data Structures/README.md`.
