# 앱 프로그래밍 1주차 + 중간고사 시험 정리..
## 1. 바이브 코딩이란
코드를 직접 타이핑하는 대신, 자연어(일상 언어)로 AI와 대화하며 소프트웨어를 만드는 방식

## 2. 바이브 코딩의 사이클
1. 아이디어 정의

2. 프롬프트 작성

3. 결과 확인

4. 수정 요청

5. 검토 및 기록

※ 반복 개선이 핵심

## 3. AI 코딩 도구의 분류
### 1) 모델 선택형 도구
- 여러 AI 모델 중 골라 쓰는 도구
- 예: Cursor, Replit, Windsur

### 2) 자체 모델형 도구
- 자체 AI 모델만 사용하는 도구
- 예: Claude Code, Gemini CL

## 4. AI 어시스턴트의 발전 과정
1. 뉴럴 네트워크 → 사람의 뇌를 모방한 기초 인공지능

2. 딥러닝 → 이미지, 음성인식 방면에서 사용

3. 트랜스포머 → 문장의 맥락을 이해

4. LLM → 사람과 대화하듯 코드를 작성해주는 AI

## 5. 클로드 코드의 강점 (4가지)
- artifacts: 코드를 실행하면 미리보기 제공

- publish: 결과물을 링크로 공유 가능

- customize: 대화로 기능/디자인 수정 가능

- 무료 사용 가능: 기본 기능 무료

## 6. 바이브 코딩 사용 시 주요사항
- 코드를 이해하려고 노력하기

- 보안 주의 (AI 생성 코드에 취약점 있을 수 있음)

- 검토 필수

- 프로토타이핑에 효과적

# 앱 프로그래밍 2주차

### 1. 컴퓨팅 사고력 4가지
1. 분해: 큰 문제를 작은 문제로 나누기

2. 패턴 인식: 반복되는 구조 찾기

3. 추상화: 핵심만 뽑아내기

4. 알고리즘: 순서대로 절차 밟기

### 2. 좋은 프롬프트의 3가지
- 명확성: 추상적이지 않고 구체적으로 제시

- 구체성: 조건을 디테일하게

- 맥락 제공: 왜 쓰이는지, 어떤 상황에서 쓰이는지

### 5W1H
- Why: 왜 만드는지

- Who: 누가 사용하는지

- Where: 어디서 사용하는지

- When: 언제 사용하는지

- What: 무엇을 만들 건지

- How: 어떻게 만들 건지
