## 바이브 코딩의 정의와 핵심
바이브 코딩이란?
- 자연어(일상 언어)로 **"이런 걸 만들어 줘"** 라고 말하면 AI가 코드를 생성해 주는 개발 방식
- 코드를 직접 타이핑하는 대신 -> 대화와 피드백으로 소프트웨어를 만듦
* 핵심 포인트: AI가 대신 해주는 것이 아닌 함께 만들어감

### 바이브 코딩의 기본 사이클
반복 개선(Iteratio)
1. 아이디어 정의 -> 2. 프롬포트 작성 -> 3. 결과 확인 -> 4. 수정 요청 -> 5. 검토 및 기록
