# 자료구조의 이해

## 자료구조의 개념
자료르 효율적으로 표현하고 저장하고 처리할 수 있도록 정리하는 것이 자료구조

## 자료구조의 분류: 형태
### 단순 구조
  * 정수, 실수, 문자, 문자열, 등의 기본 자료형
 
### 선형 구조
  * 자료들 사이의 관계가 1:1 관계
  * 순차 리스트, 연결 리스트, 스택, 큐, 데크 등
 
### 비선형 구조
  * 자료들 사이의 관계가 1:다, 또는 다:다 관계
  * 트리, 그래프 등
 
### 파일 구조
  * 서로 관련 있는 피륻로 구성된 레코드의 집합인 파일에 대한 구조
  * 순차 파일, 색인 파일, 직접 파일 등

## 자료구조의 분류: 입출력 방향

### 1.FIFO (First-in, First-Out)
**선입선출** ex.가장 먼저 줄을 선 사람이 가장 먼저 입장하는 맛집 대기열과 같음 
  * 특징: 데이터가 들어온 순서대로 처리됨
  * 관련 자료구조: 큐(Queue)

### 2. Stack(스택)
**LIFO(Last-in, First_out, 후입선출)** ex. 프링글스 과자 통이나 쌓여 있는 접시들
  * 동작:
      * push: 데이터를 맨 위에 쌓음
      * pop: 맨 위에 있는 데이터를 꺼냄
  * 특징: 가장 마지막에 넣은 데이터를 가장 먼저 꺼냄

### 3. Deque(데크)
**Double-Ended Queue** 양쪽 끝에서 삽입과 삭제가 모두 가능한 유연한 구조
  * 특징: 스택과 큐의 장점을 모두 합친 형태로 상황에 따라 스택처럼 쓸 수 있고, 큐처럼 쓸 수 있음
  * 장점: 데이터의 앞과 뒤 모두에서 접근이 가능하므로 매우 효율적
  * 활용: 데이터의 양방향 탐색이 필요한 알고리즘에 쓰임

## 자료의 표현

### 1. 컴퓨터에서의 자료 표현
  * 비트(Bit): 0과 1을 담는 **최소 단위** 1비트: 0,1 (2^1= 2 개)
  * 표현 가능 상태(2^n): 비트가 n개 있으면 2의 n제곱만큼의 경우의 수를 표현할 수 있음
  * 니블(Nibble): 4비트 그룹
  * 바이트(byte): 8비트 그룹 = 2^8=256개 



## 총 정리
자료구조는 단순히 데이터를 저장하는 방식이 아니라, 문제를 해결하는 효율적인 도구이다.
- 선형 구조 → 순차적 처리에 강점
- 비선형 구조 → 복잡한 관계 표현에 강점
- 입출력 방식 → 상황에 맞는 데이터 처리 전략 제공

## 1. 선형 리스트
- 개념: 원소들이 순서대로 나열된 자료구조. (배열을 이용한 순차 자료구조)
-  삽입 이동 횟수: n-k+1 (k번째 자리를 비우기 위해 K번부터 끝까지 뒤로 밀기)
-  삭제 이동 횟수: $n - k$ (k번째가 빠진 빈자리를 채우기 위해 k+1번부터 끝까지 앞으로 당기기)

## 2. 희소행렬
- 정의: 원소 중 0이 대부분인 행렬
- 저장 방식: 0ㅇ르 제외한 **(행,열,값)**의 3원소 쌍으로 저장.
- **2차원 배열 표현(논리적 구조):**
   - **0번 행:** <전체 행 개수, 전체 열 개수, 0이 아닌 원소 개수>
   - **1번 행:** 실제 값이 있는 위치와 값 <i, j, value>
- 장점: 메모리 공간 절약

## 3. 다항식의 표현
- 차수: 다항식에서 가장 높은 지수
- 항의 개수: 계수가 0이 아닌 실제 항들의 수
- **희소다항식의 선형 리스트 표현:**
  - 각 항을 **(지수,계수)** 쌍으로 묶어서 리스트의 원소로 정의.
  - $4x^3 + 7 \rightarrow ((3, 4), (0, 7))$

-**저장 방식 비교:**
 - **일반 배열::** A[차수+1] 크기로 선언.(계수만 저장, 인덱스가 지수 역할)
 - **희소 방식(1차원):** [지수1, 계수1, ...] 순으로 나열
 - **희소 방식(2차원):** 각 행마다 [지수, 계수]를 저장

## 4. 주소 위치 계산 (행 우선 순서)
- **핵심:** 2차원 배열 A[m][n]에서 A[i][j]의 주소는?
   - **공식:** 시작주소 + (i* 전체 열 개수 +j) * 데이터크기
   - **이유:** i행까지 가려면 앞의 i개 행(각 행마다 n개 원소)을 다 지나쳐야함.
